# 🍕 Pizza Sales SQL Analysis

## 📄 Project Overview
This project focuses on analyzing a **pizza sales database** using **SQL**.  
The goal is to extract meaningful insights such as total sales, popular pizza types, order patterns, and revenue trends.

The queries are divided into two levels — **Basic** and **Intermediate** — to demonstrate progressive data analysis skills.

---

## 🧩 Dataset Description
The database consists of multiple tables (commonly named as):
- **orders** – Contains order-level details such as order ID, date, and time of each order.
- **order_details** – Contains individual pizza items for each order, including order details ID, order ID, pizza ID, and quantity.
- **pizzas** – Includes details of each pizza such as pizza ID, pizza type ID, size, and price.
- **pizza_types** – Contains descriptive information for each pizza type, including pizza type ID, name, category, and ingredients.

🧩 Insights & Findings
🔥 Major Insights
- **Greek Pizza** commands highest price point, driving premium revenue segment.
- **Large size** dominates orders (highest count across all categories).
- **Classic Deluxe, BBQ Chicken, Hawaiian** claim top 5 spots by total quantity sold.
- **$818K total revenue** from 21,350 unique orders (avg $38.30/order).
- **48,620 order details** reveal multi-pizza orders as revenue driver (2.32 avg pizzas/order).
- **Pareto Effect**: Top 5 pizzas account for disproportionate sales volume.

💡 Business Recommendations
- **Prioritize Large-size production** and inventory for Supreme/Classic categories.
- **Cross-sell Greek Pizza** as premium upsell option in combos.
- **Target Top 5 performers** for loyalty program discounts.
- **Optimize menu** by promoting high-quantity sellers during peak hours.
- **Dynamic pricing** for low-volume pizzas to clear inventory.
