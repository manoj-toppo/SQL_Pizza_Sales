# 🍕 Pizza Sales SQL Analysis

## 📄 Project Overview
This project focuses on analyzing a **pizza sales database** using **SQL**.  
The goal is to extract meaningful insights such as total sales, popular pizza types, order patterns, and revenue trends.

The queries are divided into two levels — **Basic** and **Intermediate** — to demonstrate progressive data analysis skills.

---

## 🧩 Dataset Description
The database consists of multiple tables (commonly named as):
- **orders** – Contains order-level details such as order ID, date, and time of each order.
- **order_details** – Contains individual pizza items for each order, including order details ID, order ID, pizza ID, and quantity.
- **pizzas** – Includes details of each pizza such as pizza ID, pizza type ID, size, and price.
- **pizza_types** – Contains descriptive information for each pizza type, including pizza type ID, name, category, and ingredients.
